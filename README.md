# Small Business Network Design

## Project Overview

This project focuses on the design and configuration of a Local Area Network (LAN) for a small multi-floor organization using Cisco Packet Tracer.

The network is designed to provide reliable connectivity, efficient resource sharing, secure communication, and easy management between different departments while allowing future expansion.

## Objectives

- Design a reliable network for a multi-floor organization.
- Provide connectivity between different departments.
- Separate departments using VLANs.
- Enable communication between VLANs through routing.
- Configure wired and wireless network connections.
- Provide automatic IP address assignment using DHCP.
- Configure DNS and web services.
- Enable communication between staff using VoIP.
- Create a scalable network structure for future expansion.

## Network Components

The network includes:

- 4 Cisco 2811 Routers
- 5 Switches
- 11 PCs
- 3 Servers
- 4 Laptops
- 2 Printers
- 3 Wireless Access Points
- IP Phones

## Network Configuration

The network was configured using Cisco Packet Tracer. Routers were configured with IP addresses and connected using serial connections.

VLANs were implemented to separate departments, while inter-VLAN routing was configured to allow communication between different network segments.

IP addresses and subnet masks were assigned according to the network addressing table.

## Network Services

The project includes several network services:

- **DHCP:** Automatically assigns IP addresses to devices.
- **DNS:** Provides domain name resolution.
- **Web Server:** Provides web hosting services.
- **VoIP:** Enables communication through IP phones.
- **Wireless Access:** Provides wireless connectivity for laptops and other devices.

## Wireless Network

Access points were configured to provide wireless connectivity for departments. Laptops and printers were connected to the wireless network using the configured SSID and password.

## VoIP Configuration

IP phones were configured to support communication between staff members. The routers and switches were configured to provide the required VoIP functionality.
